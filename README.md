# 🌸 Floriography – The Language of Flowers

**Floriography** is a creative web application inspired by the Victorian tradition of communicating through flowers. It allows users to explore the symbolic meanings of different flowers and discover a floral interpretation of their names.

## ✨ Features

- **Alphabetical Flower Dictionary:** Explore a collection of flowers organized from A to Z.
- **Random Flower Discovery:** Select an alphabet letter to discover a randomly selected flower along with its symbolic meaning.
- **Name-Based Flower Discovery:** Enter your name to receive a collection of flowers corresponding to its individual letters.
- **Floral Visuals:** Explore flower images alongside their meanings.

## 🛠️ Technologies Used

- C#
- ASP.NET MVC
- HTML5
- CSS3
- JavaScript
- Bootstrap

## 📂 Project Structure

- **Models:** Contains the `FlowerModel` class, which stores flower details such as name, letter, meaning and image path.
- **Views:** Contains the pages for the flower dictionary, name input and personalized flower results.
- **Controllers:** Handles flower data, random flower selection and name-based flower matching.
- **Project Images:** Stores the flower images and background visuals used throughout the application.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Suter-cpu/-Floriography.git
   ```

2. Open the project in **Visual Studio**.

3. Open `Floriography.csproj`.

4. Restore the required NuGet packages.

5. Build the project to check for errors.

6. Run the application using **IIS Express** or Visual Studio's Run option.

7. Explore the flower dictionary and try the name-based flower discovery feature.

### Requirements
- Windows
- Visual Studio with ASP.NET MVC development support
- .NET Framework compatible with the project configuration
